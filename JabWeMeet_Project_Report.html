Executive Summary

JabWeMeet is a modern full-stack social connection and relationship ecosystem. Engineered to transcend superficial swipe-and-match dating paradigms, JabWeMeet emphasizes real-world connections, human-guided matchmaking augmented by generative artificial intelligence, and dedicated post-relationship emotional healing services.

4. WebRTC Voice Calling & Real-Time Timers

The Breakup Buddy voice consultation system utilizes WebRTC peer-to-peer audio with a Socket.io signaling server running on port 5001. A key innovation in the platform is server-authoritative timer enforcement:

  • When a call is accepted, the server starts an active interval updating the database every 5 seconds.
  • If voiceCallSeconds >= voiceCallLimitSeconds (default 300s / 5 mins for free tier), the server broadcasts a forced call-ended event to both peers.
  • The frontend automatically displays a subscription renewal or minute top-up modal upon expiry.

5. Google Gemini AI Matchmaking Engine

In backend/routes/matchmaker.js, the platform leverages Gemini 2.5 Flash to provide objective compatibility scores between clients and candidates based on:

  • Demographic vectors (Age, Gender, City).
  • Relationship intentions (Long-term, Marriage, Companionship).
  • Lifestyle habits, personality traits, and questionnaire responses.
